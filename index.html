リンク作成は、3つの手順で

              

                
  1. ゲームを選ぶ
    原神・スターレイル・ゼンゼロから対象を選択。色とアイコンが作品に合わせて切り替わります。
  2. コードを貼り付ける
    1行に1コード。入力するとリンクが自動でできます。スマートフォンでは「共有」で表示を切り替えます。
  3. コピーして共有する
    URLかMarkdownをコピー。公式ページも1件ずつ開け、開いた行には「開済」目印が付きます。

                
入力と結果の例
sample123
SAMPLE123
重複をまとめて、1件のリンクに。
SAMPLE123選んだゲームの公式交換ページ
説明用のコードです。有効なコードではありません。

              

              
            

            
コード入力のポイント
コードだけでなく、選択中の作品の公式交換URLも1行ずつ貼り付けられます。別作品のURLや不正なURLは理由を表示して除外します。

              
20件まで10,000文字まで半角英数字

              
小文字・重複
大文字に統一し、同じコードは1件にまとめます。「整理」で入力欄も整えられます。整理・クリアは「元に戻す」で1回戻せます。手入力や履歴復元の後は古い取り消しを使えません。
入力エラー
記号などを含む行は理由を表示して除外します。上限を超えたら処理を止めるので、入力を減らしてください。
貼り付け
貼り付けボタン、または入力欄で Ctrl + V。スマートフォンでは長押しでも貼り付けられます。

              
コードは1〜128文字の半角英数字として検証します。有効期限や利用可否は公式ページで確認してください。

            

            
共有先に合わせてコピー

              
URL
交換ページのアドレスを、そのまま共有したいときに。
https://hsr.hoyoverse.com/gift?code=SAMPLE123
Markdown
Discordでコード名付きのリンクとして共有したいときに。
[交換コード：SAMPLE123](公式交換URL)

              
「URL / Discord用」から形式を選ぶと、対応するコピーボタンを表示します。各コードの右側では、1件だけのコピー・公式ページの表示もできます。

              
Markdownの見出しと表示の保存
「Discord用」を選ぶと、大きい・中くらい・小さい見出し・なしを設定できます。ゲーム・表示形式・見出しは、ブラウザ保存がONのときに記憶します。

            

            
Discordの送信先を登録

              
  1. チャンネルの設定を開く
    Discordで投稿したいチャンネルの「設定」を開きます。
  2. Webhookを作成する
    「連携サービス」→「ウェブフック」で作成し、URLをコピーします。
  3. このサイトに登録する
    「Discord設定」の「追加」で対応ゲーム・表示名・URLを入力し、「送信先を登録」。最大10件まで登録できます。
  4. テスト送信で確認する
    登録した送信先の「テスト送信」で、チャンネルに届くか確認します。

              
Webhook URLは投稿権限を持つ秘密情報です。公開・共有せず、表示切替は必要なときだけ使ってください。

              
登録内容の変更・旧設定の引き継ぎ
名前・URL・ゲームは送信先の「編集」から変更できます。旧設定はゲーム未設定・無効の状態で引き継ぎます。対応ゲームを設定し、必要な送信先だけをONにしてください。

            

            
確認してから、まとめて送信

              
  • 選択中のゲームに対応する、ONの送信先だけが対象
  • 送信前にゲーム・コード数・送信先名・総投稿数を確認
  • 同じコードの再送は警告を表示。再告知も可能

              
5送信先 / 回10投稿 / 回2,000文字 / 投稿

              
長い本文はコード単位で分割します。通常送信と再送は操作全体で30秒、テスト送信は送信先ごとに60秒の待機時間があります。

              
一部成功・失敗・再送の扱い
成功・一部成功・失敗を区別して表示します。「Discord設定」→「送信履歴」の「再送」は、失敗したメッセージだけが対象です。Discordから待機時間が指定された場合は、そちらを優先します。自動再試行は行いません。
8秒以内に応答がなければタイムアウトします。通信が途切れても届いている可能性があるので、チャンネルを確認してから再送してください。不正なURLや権限エラーの送信先は停止します。

            

            
保存するかは、自分で選べます

              
保存ON 初期設定
Webhookと履歴をこのブラウザに保存。再読み込みしても利用できます。
保存OFF
Webhookは現在のタブだけで保持。再読み込みすると消えます。

              
「Discord設定」→「保存・移行」で切り替えられます。運営サーバーへの保存・同期は行いません。送信時のみDiscordへ内容を送ります。

              
「Discord設定」→「保存・移行」に書き出し・読み込みをまとめています。設定のみの書き出しにはURLを含みません。「URL付きバックアップ」には秘密情報が含まれます。公開場所へ置かないでください。

              
保存範囲・削除・JSON読み込みの詳細
  • 保存OFFへの切り替えは全タブに反映し、履歴・送信済み記録も永続保存しません。連打防止用の時刻とWebhook識別番号だけは共有します。
  • 全データ削除はWebhook・履歴・送信済み記録・ログ・入力内容を削除します。連打防止用の時刻とWebhook識別番号は保持します。
  • 読み込めるJSONは100KB・10件まで。不正なファイルは既存設定を変更しません。旧サイトからは自動移行しないため、JSONで移行してください。
  • 送信済み記録はゲーム・コード・Webhook識別番号・送信日時だけを最大30日・1,000件保持します。
ブラウザ保存は暗号化されません。共有端末では保存OFFを使い、信頼できない拡張機能に注意してください。

            

            
困ったときは

              
貼り付けボタンが使えない
ブラウザがクリップボードを許可していません。入力欄を選んで Ctrl+V、または長押しの「貼り付け」を使ってください。

              
Discord送信に失敗する
対応ゲーム・Webhook URL・ON/OFF・Discord側の権限を確認してください。通信・CORSエラーの場合は届いているかチャンネルを確認し、表示された待機時間の後に手動で再送してください。

              
交換ページを開けない
各コード右側の「開く」を1件ずつ利用してください。ブラウザのポップアップ制限も確認してください。

              
表示が更新されない
ページを再読み込みしてください。保存OFFの場合、再読み込みで現在のタブのデータは消えます。
